# Petal Bloom — Online Flower Shop

Petal Bloom is an online flower shop where customers can browse flowers, view prices, add flowers to their shopping bag, and place orders. The owner can also manage flower products and customer orders.

## Features
- Browse flowers and prices.
- Add flowers to the shopping bag and calculate the total.
- Place customer orders.
- Add, update, and delete flower products.
- Manage customer orders.

## What I Learned
I learned how to build a website, connect APIs, manage flower products, calculate shopping totals, save customer orders, test my code, and track my progress during development.

## Project Goal
My goal was to create a simple, user-friendly online flower shop and improve my web development skills through practical experience.
